# Prototipo: cuenta única (Mi negocio / Mis fiestas)

Prototipo navegable, no es código de producción.

- `cuenta.html`: la cuenta (entrada con WhatsApp, perfil y las dos pestañas).
- `reg_src.html`: pestaña **Mi negocio** (registro del proveedor), con el venue armado por piezas.
- `cot_src.html`: pestaña **Mis fiestas** (cotizador), emparejado con los venues.
- `catalogo.js`: **catálogo compartido** (tipos de venue, características, servicios) y el motor del
  **precio estándar ¡HQV!** (`venueQuote`, `standardPrice`). Es la pieza que pasará tal cual a producción.

Regla estándar: 5 h de fiesta + ½ h de montaje + ½ h de desmontaje.
