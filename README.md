# ¡Hay que vernos!

La red de proveedores de fiestas de México: los proveedores crean su sitio web gratis y los anfitriones pre-cotizan su fiesta por persona.

Este repositorio contiene el código de la plataforma (en construcción).

- **Stack previsto:** Astro + Supabase + Cloudflare Pages.
- **Lanzamiento del cotizador para anfitriones:** 1 de noviembre de 2026.
